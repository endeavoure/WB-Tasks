### Гайд по репозиторию
#### Файлы, содержащие решения задач:
1. ***task1.md*** — файл, содержащий ответы на вопросы первого задания по **Data Quality Theory**.
2. ***task2_eda.ipynb*** — файл, содержащий EDA датасета **Ship Performance Clustering** — часть **Data Quality Assignment**.
3. ***task2_tests.ipynb*** — файл, содержащий код запуска SODA проверок над потоком данных из датасета — часть **Data Quality Assignment**.
4. ***task3.ipynb*** — файл, содержащий решение **Python Assignment** — задачка на питоне.
5. ***task4.sql*** — файл, содержащий решение **SQL Assignment** — задачка на SQL.

#### Другие файлы и папки:
- ***requirements.txt*** содержит требования по библиотекам для того, чтобы запустить код у вас локально. С помощью этого файла можно установить все необходимые зависимости одной строчкой в терминале.
- ***soda/checks.yaml*** содержит проверки, написанные на SODA.
- ***logs/soda_logs.log*** содержит логи результатов проверок над потоком данных.
- ***data/Ship_Performance_Dataset.csv*** — собственно сам датасет, используемый в **Data Quality Assignment**.
